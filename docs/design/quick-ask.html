Same silhouette as the Quick switcher. Typing searches the index; ⌘↵ turns the same popup into a one-shot answer, then hands off to the sidebar. Try typing, then press ⌘↵ or click the "Ask the agent" row.

Argon2id cost presets

Argon2id cost presets

Default is 64 MiB with 3 iterations. The High preset is 128 MiB with 4. A key slot above the default makes the plugin ask through a cost dialog before unlocking; Cancel is the default answer.

A phone may not be able to unlock High. That was not measured, which is why the [[Measure key derivation time]] command exists.
