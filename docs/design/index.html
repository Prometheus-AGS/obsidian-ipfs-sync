Three surfaces

One view to work in, one popup to ask once, one place for every setting.

Vault agent view

A right-sidebar leaf with Search, Chat and Index tabs. Chat has two modes: Notes, a retrieval-only chat that answers from your passages and cites each sentence, and Agent, which adds skills, tools and approval cards.

Quick ask

The Quick switcher's silhouette. Type to search by meaning; ⌘↵ turns the same popup into a one-shot cited answer that hands off to the view. On a phone it is a bottom sheet.

Control center

Searchable settings in six sections, with Security first-class: device identity, pairing, grants with expiry, and consequence dialogs on every destructive action.

What makes it this plugin

Honesty about the index, the lane and the skills.

  1. 01The index is a cache and says so. Model, coverage, what is pinned to the snapshot, one tap to rebuild. iOS eviction becomes a rebuild, not a loss.
  2. 02A lane chip on every agent surface. Local, Remote or Offline, with the model or endpoint. A question that left the device looks different from one that did not.
  3. 03Skill activations are never hidden. Name, source, description and arguments stay visible; tool calls, thinking and errors collapse but are always reachable and copyable.
  4. 04Native first. Obsidian variables only, sentence case, no default hotkeys, Lucide icons, DOM built with the Vault API's helpers. The user's theme and accent apply unchanged.
  5. 05One mechanism per job. Finding is Search, asking is Chat, configuring is the control center. Nothing is duplicated on one screen.
