## New findings
- **N2-01 MEDIUM — blob reader keeps every consumed chunk until the queue passes 1,024 entries** (blob.ts:279-292): `this.head++` leaves the reference in `this.chunks`; compaction only when `head > 1024 && head*2 > length`; with 256 KiB chunks up to ~256 MiB of consumed chunks stay live — breaks the "at most two segments live" bound of task 3.4. Fix: set the consumed slot to a shared empty array before `head++`; test with WeakRef/instrumented source. Before 3.4.
- **N2-02 MEDIUM — no import-boundary lint for the crypto module; name lint misses forging/raw-key paths** (tools/hook-isolation.mjs:163-193): `RESTRICTED_SYMBOLS` lacks `markParsed`/`assertParsed` (a deep import can register a Proxy/getter document in the WeakSet and defeat the brand), `createVaultKeys`/`createVaultKeysFromHex`, `deriveKek`, `KdfFunction`, `secureRandom`, `randomBytes`, `RandomSource`; `PLATFORM_PRIMITIVES` is an unfrozen exported object. Fix: outside `src/crypto/**`, `tests/**`, `tools/**` imports resolving into `src/crypto` must resolve to `src/crypto/index.ts` (sole exception `src/sync/encrypted-manifest.ts`); add names to `RESTRICTED_SYMBOLS`; `Object.freeze(PLATFORM_PRIMITIVES)`; move `createVaultKeysFromHex` to tests/support; negative test. Before 3.2; may run in parallel with 3.1.
- **N2-03 LOW — injection lint narrow; injectables ship inside the bundle.** `INJECTION_PROPERTY` matches only `deps:`/`random:` (misses `kdf`, `selfTest`, `exponent`, `limits`, shorthand, quoted keys); globs only `.ts/.tsx/.mjs/.js`; allow-list per file, not per symbol; `unwrapVckInternal`, `createKeySlotsInternal`, `*With` variants are in the shipped bundle where sentinel/metafile checks cannot see them. Fix: widen the rule and extension list; long-term move injectable wrappers under `src/crypto/testing/*`.
- **N2-04 LOW — public index exports low-level primitives that accept caller nonces/raw keys** (`aesGcmEncrypt(key, nonce, …)`, `importAesGcmKey`, `importHkdfKey`, `hkdfSha256`, `deriveAesGcmKey`, `importHmacKey`; `encryptManifestEnvelope` skips the validating writer). Fix: remove from the index (tests deep-import); `encodeManifestFile`/`decodeManifestFile` are the only manifest entry points for wiring. Before 3.2.
- **N2-05 LOW — format freeze: `device` has no charset rule** (encrypted-manifest.ts:258-260): lone surrogates, control chars, newlines, bidi overrides accepted. Decide now: reject lone surrogates and U+0000..U+001F/U+007F; add a row to production and the reference cross-check. Before 6.2.
- **N2-06 LOW — a temporary copy of the passphrase body is not wiped** (passphrase.ts:61 `concatBytes(label, body)`).
- **N2-07 LOW — error mapping leaves masking paths:** `deriveKek` catches everything (a host `onProgress` exception becomes "cannot afford"); `approveCost` exceptions propagate raw; `secureRandom` unguarded; `aesGcmDecrypt` maps every platform failure to `authentication-failed` (a resource failure on a 16 MiB segment reads as tampering; wiring might quarantine instead of retry). Fix: `kdf-unaffordable` only for RangeError/allocation failures; wrap `approveCost` errors as `kdf-cost-refused`; guard `getRandomValues`; map only `OperationError`/`DataError` to `authentication-failed`, everything else `platform-failure` (confirm for WebKit).
- **N2-08 LOW — cost policy refinements:** the prompt runs before `requireSubtle`/self-test (user can approve 128 MiB then get `crypto-unavailable`) → move those checks ahead; `kdf-cost-refused` carries no structured params → `KdfCostRefusedError` with `slots: KdfParams[]`; a hostile second slot blocks unlock even when slot 1 would succeed (consistent with "validate all tried slots first"); `approveCost` has no timeout (host concern).
- **N2-09 LOW — `markParsed` freezes only the document and `slots` array;** slot/`kdf`/`wrap`/unknown-slot `raw` stay mutable → deep-freeze.
- **N2-10 LOW — `CanonicalPassphrase` proves format, not generation:** `computePassphraseCheck`/`formatPassphrase` exported; a caller can build a low-entropy 23-symbol body + valid check and `createKeySlots` accepts it. Fix: second WeakSet brand for `generatePassphrase()` output; `createKeySlots` accepts only that; unlock still accepts canonicalised input; remove `computePassphraseCheck` from the index.
- **N2-11 LOW — new test-quality gaps:** `checkDistBundles` violation path never exercised (the "nonexistent root" case passes only because `loadSentinels` throws); G-12 wall-clock test cannot fail; no tests for `structuredClone`/Proxy/`Object.create` documents, `approveCost` throwing/rejecting, cost-prompt ordering vs `crypto-unavailable`; `strict-json.test.ts:52` uses `toBeDefined()`.
- **N2-12 INFO — esbuild options:** structure consistent with the old build (same banner, cjs/es2022 plugin; CLI shebang, createRequire shim, esm/node24); sourcemap off in prod; could not diff the old config (no shell); non-prod honours `OBSIDIAN_PLUGIN_DIR` (confirmed pre-existing dev behaviour).
- **N2-13 MEDIUM (blocks guard lift and Release 2, not section 3) — wire `checkDistBundles` into the release tooling:** it runs only inside `tools/webview-import-probe.mjs:82-84` where the pass condition is `dist.ok` (ignores `missing`, so an absent or stale dist passes); `tools/release-mvp-05.mjs` does not call it. Required before the guard is lifted and before Release 2: the release script builds production, runs `checkDistBundles`, requires `missing` and `violations` empty, confirms scanned bytes equal the files hashed into SHA256SUMS; planted-sentinel test.
