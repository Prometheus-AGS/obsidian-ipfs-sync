## Decisions beyond the brief
- **Timer path passes a recorder, not nothing.** The engine's mass-removal refusal carries text only, no counts, and the timer notice needs them. The runner hands the engine a `confirmMassRemoval` that stores the counts and returns `false` for an unattended run (and for a manual run with no dialog port). It never asks and never answers yes, so the timer still cannot confirm. The alternative was editing `publish-refusals.ts` to carry counts on the error.
- **Manual publish asks inside the lock.** The guard runs inside the engine after the plan, so the mass-removal dialog opens while the in-process lock and `publish.lock` are held. A dialog left open for more than 15 minutes ends the file lock's heartbeat window; the publish then refuses at its next `assertHeld` and writes nothing. Stated limit.
- **Accept holds both locks from a good check until Accept ends or the dialog closes.** The prepared acceptance is a view of the node taken under the lock. Publish and pull show "a key-management action is already in progress" meanwhile. Closing the dialog, a failed commit, a successful commit and plugin unload all give the locks back.
- **After a rewrap or an accepted change the session is locked and re-read** (`afterChange`): the held keys were opened from the old key-slot file, and a publish with them would answer "locked" once.
- **`failureOf` retryable set:** wrong or malformed passphrase, a busy lock, and `lock-held` (lock file taken elsewhere). Nothing else is retryable, including refusals that wrote nothing but that a second try cannot fix (maintenance pending, no record, no key slot copy).
- **Generated passphrase is made by the flow**, not the dialog: `generatePassphrase()` at open, `formatPassphrase` for display, wiped when the dialog finishes.
- **`key-ports.ts` duplicates the assembly of `cli/keys-session.ts` `openKeyPorts`** (about 40 lines) because the CLI file builds a Node host and cannot be imported into the WebView bundle. A shared builder in `src/sync/` would remove the copy; not done (out of scope, working code).
- The measure command's heartbeat counts the stretch from the last tick to the end, so a loop blocked for the whole derivation reports that whole time as the gap.
