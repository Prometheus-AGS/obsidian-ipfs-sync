- Every dialog's `run` / `checkSlots` / `accept` callback returns the REAL outcome (the `settleUnlock` contract, re-read 2.1(b)). Only `ok: true` ends as done. `retryable: true` only for a refusal that wrote nothing (wrong passphrase); anything else locks the form and ends `stopped`.

## Accessibility checklist
Checked by `tests/unit/key-management-dialogs.test.ts` and `encryption-key-actions-section.test.ts` (fake DOM), not by a screen reader.
- [x] Visible label for every control; `aria-labelledby` on fields, radios, checkboxes; asserted for every focusable control.
- [x] Errors are words ("Error: ...") in a polite live region tied to the field by `aria-describedby`; `aria-invalid` set; colour is a bonus only.
- [x] Masked inputs (`type=password`, autocomplete/spellcheck off) with a reveal checkbox each.
- [x] Keyboard: reading-order tab sequence asserted per dialog; native radios (arrow keys inside the group, one Tab stop); Enter submits only when gating holds; Escape/close is a no.
- [x] Initial focus: removal dialog on Cancel (asserted); key dialogs on their first field; after a retryable failure on the field; after an end state on Close.
- [x] Statement gating: change-passphrase and increase-cost confirm disabled until the acknowledgement is ticked; lower cost and cheaper incoming slots need their own tick; the blocking requirement is a sentence in a live region described by the button.
- [x] State by words: end states show "Passphrase changed" / "Not finished" and the test unlock result as text; progress as text plus native `<progress>`.
- [x] No clipboard control anywhere (none, not mobile-only); generated passphrase is selectable text in monospace; source scan forbids `clipboard`/`execCommand`.
- [x] No HTML sinks: source scan forbids `innerHTML`, `outerHTML`, `insertAdjacentHTML`; callers' reasons pass `escapeForDisplay` then `textContent`.
- [x] Target size / touch: native Obsidian buttons, checkboxes and radios (theme sizing); no custom pixel sizes set. Unverified on a phone.
- [ ] Not verified: real screen reader announcement, contrast in light/dark themes, Obsidian mobile keyboard overlap, reduced motion (no motion used), narrow-width wrapping of the 5-group passphrase (uses flex-wrap).
- Inherited from Obsidian's `Modal` and not set here: dialog role and focus trap.
