Floor refusal, passage-only prompt, per-sentence passage markers from the pipeline, Quote only, no provider fallback. The refusal is structural: when no passage passes the floor, or coverage is below the floor, the service makes no model call at all, so "never answers from model knowledge" holds by construction, and the refusal is returned as data (`no-index`, `below-floor`, `out-of-scope`).
